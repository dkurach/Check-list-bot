# Check-list bot

Telegram-бот для задач в общем рабочем чате. Бот публикует задачи по расписанию, отмечает исполнителей из текущей смены и считает задачу выполненной, когда исполнитель ответил на её сообщение фото или текстом. Если срок прошёл, бот напоминает исполнителю в личку, а потом сообщает старшим смены и администратору.

Работает на обычном компьютере с Windows или macOS: сервер, домен и белый IP не нужны.

## Установка

1. Создайте бота в [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Скачайте проект (Code → Download ZIP) и распакуйте в постоянную папку.
   - Windows: например, `C:\check-list-bot`.
   - macOS: в домашнюю папку, например `~/check-list-bot`. Папки «Рабочий стол», «Документы» и «Загрузки» не подходят: у фоновых служб macOS нет к ним доступа.
3. Запустите установщик двойным щелчком:
   - Windows: `install.bat`;
   - macOS: `install.command` (если macOS не даёт открыть файл, щёлкните по нему правой кнопкой → «Открыть»).
4. Введите токен и часовой пояс. Установщик скачает всё нужное, включит автозапуск и покажет ссылку для главного администратора.
5. Главный администратор открывает эту ссылку и нажимает «Старт».
6. Добавьте бота в общий чат, назначьте его администратором и отправьте в чате `/bind`.
7. Сотрудники пишут боту `/start` в личку, администратор подтверждает их в меню.

Чтобы бот не засыпал вместе с компьютером, отключите сон при работе от сети. Пока бот работает, он сам не даёт системе уснуть, но закрытая крышка ноутбука всё равно может отправить его в сон.

## Обновление

Двойной щелчок по `update.bat` (Windows) или `update.command` (macOS). Если проект скачан архивом, сначала распакуйте новую версию поверх старой, не трогая файл `.env` и папку `data`.

## Как пользоваться

Меню в личке с ботом (для администратора и старших смены):

| Кнопка | Что делает |
|---|---|
| 📅 Смена | Отметить, кто работает сегодня или завтра |
| 📋 Сегодня | Задачи дня со статусами, закрыть или отменить вручную |
| 🗂 Задачи | Список задач, пауза и удаление |
| ➕ Новая задача | Создать задачу: название, исполнитель, расписание, дни, срок |
| 👥 Сотрудники | Только для главного администратора: заявки, отключение, старшие смены |

Варианты расписания: один раз; в заданное время (`09:00, 13:00, 18:00`); каждые N минут в окне (`120 10:00-20:00`); N раз за день равномерно (`4 09:00-21:00`). Для повторяющихся задач выбираются дни недели.

Исполнитель: конкретный сотрудник или «кто на смене». Во втором случае задача адресуется всем, кто отмечен в смене, и закрывает её первый ответивший.

## Где лежат данные

Всё хранится в папке `data` рядом с программой:
- `bot.db`: база (сотрудники, смены, задачи, история);
- `backups/`: ежедневные копии базы, хранятся последние 14;
- `logs/bot.log`: журнал работы.

## Команды

Из папки проекта: `uv run python -m checklist_bot <команда>`

| Команда | Что делает |
|---|---|
| `setup` | Установка или смена токена и часового пояса |
| `run` | Запустить бота в текущем окне (для разработки) |
| `start` / `stop` / `restart` | Управлять фоновым ботом |
| `status` | Проверить, работает ли бот |
| `uninstall` | Остановить бота и выключить автозапуск |

## Разработка

```bash
uv sync
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

Для разработки заведите отдельного тестового бота и тестовую группу. Один токен может работать только в одном запущенном экземпляре, поэтому боевой бот у заказчика, а тестовый у разработчика. Настройки лежат в `.env` (пример в `.env.example`).

Устройство кода:
- `engine.py`: публикация задач по расписанию, приём ответов, просрочки, бэкапы;
- `schedule.py`: расчёт времени публикаций;
- `db.py`: SQLite и миграции (новые миграции добавлять в конец списка `MIGRATIONS`);
- `handlers/`: обработчики Telegram (общий чат, меню, мастер создания задачи);
- `service.py`: фоновый запуск и автозапуск (Windows: ярлык в автозагрузке; macOS: LaunchAgent).
